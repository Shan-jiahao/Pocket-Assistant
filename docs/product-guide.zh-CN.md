# Pocket Assistant（Pocket助手）产品介绍说明书

版本：开发验证版 · 文档日期：2026-09-05

## 产品是什么

Pocket助手是一款面向 Pocket 相机用户的中文 iPhone 控制工具。
核心功能是将耳机采集的头部方向转化为云台运动，让使用者通过转头和点头调整相机朝向。
连接管理、手动云台与拍摄控制集中在同一应用中，不需要进入视频监看页面。

适合探索头部控制拍摄、远离相机屏幕调整方向，以及将连接、云台和录制操作集中到手机的用户。
没有监看画面时，应通过相机屏幕或现场观察确认构图和录制结果。

## 功能与页面

底部菜单依次为“设备”“拍摄”“头追”。

### 设备

- 发现附近相机，完成蓝牙配对，并引导加入相机自己的 Wi-Fi。
- 显示连接阶段，保存已连接的相机，支持重连、断开与忘记设备。
- 提供连接说明与诊断报告入口。
- 提供保持屏幕常亮的使用偏好。

Wi-Fi 列表中出现相机，或系统显示已连接 Wi-Fi，不等于应用控制链路已经就绪。
仍需等待应用完成数据链路建立；以应用里的连接状态为准。

### 拍摄

- 紧凑的录制按钮：开始或停止录制；相机处于照片模式时触发拍照。
- 手动摇杆：按住拖动控制方向，松手停止驱动。
- 云台回中与旋转 180°。
- 云台水平角度、俯仰角度和手动摇杆速度。
- 电量、剩余空间、拍摄模式、曝光模式、分辨率与帧率、色彩模式状态。

画面参数目前以状态显示为主，不是完整的相机参数编辑器。
相机未连接或控制不可用时，相应操作会禁用；缺少状态数据时显示占位符。

### 头追

启动前检查耳机、Pocket、数据链路和云台姿态四项条件。
耳机的音频连接与运动数据是两回事：能播放声音不代表应用已经收到头部方向。

“校准并锁定前方”把当前头部方向与当前云台方向设为共同参考。
校准时保持头部静止；校准后转头控制水平运动，点头控制俯仰运动。
界面显示头部角度、云台角度和目标角度，便于理解跟随效果。

可在校准前点击“云台回中”，通过“查看支持耳机”阅读兼容性帮助。
快速、标准、轻柔三个预设用于快速选择响应手感，详细参数仍可单独调整。

| 参数 | 含义与影响 |
| --- | --- |
| 灵敏度 | 影响头部转动换算为目标角度的幅度 |
| 死区 | 忽略较小动作，减少细微晃动带来的云台变化 |
| 平滑度 | 调整方向变化的平滑程度；更平滑通常会降低即时响应感 |
| 最大速度 | 限制头追控制速度，避免响应过快 |

预设使用现有控制器参数，不代表不同的云台硬件工作模式。
手动摇杆速度仅影响手动操作，不改变头追参数。

## 首次使用步骤

1. 打开相机，保持手机在附近；进入“设备”页并选择目标相机。
2. 相机要求配对确认时，在相机屏幕上确认。
3. 按 iPhone 提示加入相机 Wi-Fi；没有系统提示时，前往系统设置手动加入。
4. 返回应用，等待 Pocket 和数据链路就绪。
5. 佩戴耳机，启用头追，并允许运动数据访问。
6. 等待四项条件全部就绪。必要时先将云台回中。
7. 保持头部静止，校准并锁定前方，从缓慢、小幅动作开始尝试。
8. 结束时点击停止；录制是否结束应以相机状态确认。

停止头追与停止录像是两个独立操作，不能互相替代。

## 自动停止与恢复

耳机断连、Pocket 或数据链路不可用、运动数据超时，以及应用进入后台或失活时，
系统会通过现有安全停止路径停止头追驱动并清除校准锁定。
运动数据超时阈值为 250 毫秒。恢复连接后需重新校准。

手动控制期间头追会让位。请为云台保留转动空间，不要将自动停止视为防碰撞功能。

## 设备与安装条件

- iPhone：工程最低部署版本为 iOS 17，实际兼容性以实机测试为准。
- 相机：当前主要开发目标为 Pocket 4 / 4 Pro；已有 Pocket 4 Pro 连接验证记录。
- 耳机：需要能向 iPhone 提供头部运动数据的设备，以应用实际收到样本为准。
- 权限：需要蓝牙、本地网络与运动数据权限；各权限应按使用提示允许。
- 安装：当前通过 Xcode 开发签名安装；独立仓库不等于已发布 App Store 或 TestFlight 版本。

免费 Apple Personal Team 通常不能使用 Hotspot Configuration 自动加入热点能力。
开发构建可能需要使用适配的签名配置，并在系统 Wi-Fi 设置中手动加入相机网络。
开发证书、描述文件和账号凭据不随仓库分发。

## 常见问题

### 耳机已连接，但一直等待动作数据

确认已佩戴耳机，并检查运动权限。可重新佩戴并短暂播放声音，再返回应用。
应用包含有限次数的运动流重启及读取回退；如果仍无数据，请按界面提示重试。
不要仅凭蓝牙设备名称判断兼容性。

### 相机 Wi-Fi 已连接，应用仍无法控制

检查连接的是当前配对相机的网络，等待 Wi-Fi 出现连接勾选后返回应用。
相机热点启动可能需要时间。若仍失败，查看设备页连接阶段并导出诊断报告，
不要在公开问题中上传 Wi-Fi 密码、签名材料或未经检查的个人信息。

### 校准按钮不可用

逐项检查耳机动作数据、相机连接、控制链路和云台角度。
仅音频连接成功或仅加入 Wi-Fi 都不足以满足校准条件。

### 切回应用后头追停止

这是后台安全停止行为。恢复数据后重新校准即可。

### 如何切换浅色与深色

在 iPhone“设置 → 显示与亮度”中选择外观，应用会跟随系统设置。

## 当前不包含的功能

不提供视频监看、波形图、LUT、媒体浏览、素材下载或云端交付界面。
不提供手机或相机固件升级，也未交付独立 Android 版 Pocket助手。

## 验证状态与后续验收

当前代码基线通过 594 项 Swift 核心测试及项目检查；模拟器构建、签名真机构建、
安装与启动已完成。浅色和深色界面已做模拟器检查。
以上不等于所有相机、耳机和 iOS 组合都已验证。

每次硬件验收应检查：连接与重连、动作数据、校准、两个方向跟随、停止、
手动摇杆松手停止、回中、旋转、录制起止，以及断连和切后台后的安全停止。
